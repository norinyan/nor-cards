# Nor Cards

在 Obsidian 中插入可自然编辑的 Markdown 纸卡：可选日期、折叠、三种背景与固定外壳内直接编辑。内容直接保存在所在笔记中，不使用统一任务文件，勾选后将任务移到当前卡片底部。

## 安装与使用

1. 从 GitHub 下载的 `dist/nor-cards/` 已包含安装文件；如需生成独立测试仓库，先运行下方“开发与验证”命令。然后用 Obsidian 打开本项目的 `.test-vault`，在第三方插件中启用 **Nor Cards**，查看 `Nor Cards Preview D1.3.md`。
2. 正式安装时，将 `dist/nor-cards/` 整个目录复制到目标仓库的 `.obsidian/plugins/nor-cards/`，重新加载 Obsidian 并启用插件。目录内直接包含 `main.js`、`manifest.json`、`styles.css`。
3. 在命令面板运行 **Nor Cards: Insert Nor Card**，或在设置 → 快捷键中为 **Insert Nor Card** 绑定按键。
4. 插入后直接提供一个空复选框，光标位于文字起点；Enter 续写下一条，空任务项再按 Enter 退出列表。

要求 Obsidian 1.5.0+，实际桌面验证版本为 Linux 1.14.5。正式知识库未被自动安装或修改。

## 卡片行为

- 标题默认 `Tasks`（22px / 600），点击直接修改，Enter 或失焦保存，Esc 取消；标题配置随卡片同步。标题下显示本地日期，例如 `Wed, Oct 28 · 2026`（13px / 400）。任务列表连同复选框右移 16px，标题、日期与分割线保持左对齐。点击日期打开月历，选定后保存为该卡片的固定日期，跨天不跳回今天。日期不筛选或修改任务，不记录任务日期或完成日期。
- 右侧调色板按钮单击依次切换：米白 → 浅绿 → 纯黑 → 米白。立即保存，不弹菜单，不显示下一颜色提示或悬停说明。
- 背景、选定日期和折叠状态保存在当前卡片的 Markdown 标记中，可随笔记同步，其他卡片独立。
- 小标题、段落、任务、链接、加粗等保留 Markdown 文本；小标题采用左对齐、弱化颜色。顶层任务勾选后移至卡片底部，实时预览中通过约 200ms 的缓动自然让位（系统减少动态效果时关闭），完成项按完成顺序排列；取消勾选移至未完成区末尾。缩进续行随整条任务移动，普通段落和小标题不自动排序。嵌套子任务只原位勾选，不单独搬动。
- 默认只创建一个空任务，不插入 To Do、Completed 标题。已有标题保留，可自由修改或删除。任务复选框和正文分列，续行对齐正文；正文默认 15px，单行最小高度约 34px。
- 实时预览编辑时自动保留卡片后的分隔空行，避免外部段落被原生引用块吞入；相邻卡片按独立 ID 识别，不互相合并。源码模式仍可直接修改原始 Markdown。
- **整张卡片移动（实时预览）**：悬停顶部日期栏，从右侧出现的拖动手柄，将卡片拖到当前笔记正文块之间的空白处。显示放置位置，周围内容平滑让位；松开后整体保存，正文、日期、颜色和折叠状态一同保留。支持笔记级一次撤销／重做，按 Esc 或拖到编辑器外取消；不跨笔记移动。
- **拖动排序（实时预览）**：悬停任务行后，从右侧手柄拖动；任务轻微浮起，其他任务平滑让位。松开后将完整任务及缩进续行的顺序保存到当前笔记，重新打开后保留，可随 Obsidian Sync 同步。未完成与已完成项分别在连续列表内排序，不跨标题、段落或卡片；嵌套子任务随父项移动。按 Esc 或拖到卡片外取消，不修改正文。阅读视图仍用于查看和勾选。
- **实时预览**中卡片是固定容器，单击正文即可书写，外壳、日期栏、背景、边框始终不进入编辑。正文使用独立 CodeMirror 编辑器，输入自动写回笔记，没有表单或保存按钮。点击外面只移走光标；不会将编辑器转换为另一张卡片。
- 支持正文内的中文输入、跨行选择、任务续行、复选框、标题和加粗显示，以及 Ctrl/Cmd+Z 撤销、重做。正文可输入任意 Markdown；标题、复选框和加粗作就地显示，其他 Markdown 语法不承诺完整所见即所得，源码内容完整保留。
- 可以切换 Obsidian **源码模式**检查完整卡片 Markdown；不使用上一版的整块 Callout 源码装饰。
- **阅读视图**用于查看与原生复选框交互，不提供全文编辑器。字体家族跟随 Obsidian，正文采用紧凑的 15px 默认字号，无单卡字号入口。
- 米白、纯黑、浅绿为明确选定的配色，不随系统主题自动变成另一种颜色；三者均已在明暗主题下检查。

## Markdown 与数据安全

手动检查源码时可见以下格式，通常无需自己修改标记：

```markdown
> [!nor-card|white-standard-example-id]+ Nor Card
> - [ ] 自然编辑任务
> - [x] 完成后移到下方
```

`white/black/green` 表示背景，`standard` 是兼容旧格式的占位字段，不提供字号功能；旧 `small/large` 标记仍可读取但不再改变字号。最后部分为稳定卡片 ID；`+` 展开，`-` 折叠。顶部 `Nor Card` 是源码回退标题，运行时显示当天或已选日期。手动选定日期以标题行的 `<!-- nor-date:2026-10-12 -->` 保存，其他配置变化不会重置它。

外观、日期和折叠只修改对应卡片的标题标记行，正文和无关内容原样保留。卡片内输入同步更新当前笔记编辑器中该卡片的正文范围；外观只修改标题行。阅读模式通过共享写入队列与 `Vault.process()` 修改最新文件。

如果同一卡片正文在其他视图或外部被修改，当前正文编辑器会保留本地内容并显示冲突，停止覆盖写入。请先复制需要保留的草稿，再离开并重新打开笔记，核对两个版本。卡片内撤销/重做属于正文编辑器历史；在笔记外部执行撤销导致正文变化时也按外部更新处理。重复 ID、找不到卡片或无效配置时拒绝修改并提示。请用插入命令创建新卡片；同一笔记复制整张卡片后，应给副本设置不同 ID，避免外观操作歧义。代码示例中的卡片标记不会被写入。

关闭或卸载插件后，正文仍是可读的原生 Callout 和 Markdown，样式、自动日期及外观按钮不再提供。没有后端、数据库、网络请求或第三方 Obsidian 插件依赖。

## 从 D1 升级

当前 D1.3（含任务与整卡拖动排序）对应插件版本 **2.5.0**；D1.2 为 2.1.0，D1.1 为 2.0.0，名称和插件 ID 改为 `Nor Cards` / `nor-cards`。Nor Cards 与旧版 `Norin Tasks` 是不同插件目录，安装时不要覆盖旧目录。

- 旧 `Tasks.md`、旧笔记和旧代码块不会被迁移、改写或删除。
- 建议停用旧插件；旧 `norin-tasks` 代码块不会由 Nor Cards 渲染，需要查看时可重新启用旧插件。
- D1 源码、测试和说明归档到 `archive/d1/`，旧安装文件保留在 `dist/norin-tasks/`。

## 开发与验证

```bash
cd nor-cards
npm ci
npm test
npm run package
node scripts/prepare-test-vault.mjs
```

`npm run dev` 监听源码；`npm run build` 执行 TypeScript 严格检查和生产构建。准备脚本仅更新独立测试仓库内的 Nor Cards 插件文件，以独占创建方式添加示例，不重置已有笔记或配置；已有测试配置需要自行启用新插件。

在独立 Obsidian 配置上启用本地 DevTools 端口 9333 后，可执行：

```bash
node scripts/eval-test-window.mjs < scripts/drag-check.js
```

脚本验证仓库绝对路径，只允许本项目 `.test-vault`；创建临时测试笔记并清理，不重置任务文件。详见 [PRD.md](PRD.md) 和 [TESTING.md](TESTING.md)。

尚未进行移动端真机、多个 Obsidian 版本或真实跨设备 Sync 测试。使用 Obsidian 原生笔记同步，跨设备离线冲突仍由 Obsidian Sync 处理。
